# DrukInvoice

GST-ready invoicing single-page app.

## Environment setup (Codespaces)

This project is a static frontend. No build step or backend is required.

### Prerequisites
- Python 3 (used only for a local static server)

### Run locally
```bash
python -m http.server 8000
```

Then open `http://127.0.0.1:8000` in your browser.
